TaskProjectManagement is a project and task management application where users can register and access the platform with one of two roles: User or Admin.

Administrators can create and manage projects, assign tasks to each project, and assign individual tasks to one or multiple users. Regular users can access the tasks assigned to them and manage their work.

The main goal of the application is to simplify project organization, task distribution, and collaboration between team members.

AI Usage: Little to no AI was used during the development process. Most of the project was built through manual development and problem-solving.
